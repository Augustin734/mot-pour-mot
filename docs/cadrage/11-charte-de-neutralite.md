# Charte de neutralité

L'appli rapporte ce que chaque groupe a dit, dans ses propres termes et sous la même forme pour tous ; elle ne juge jamais qui a raison. Cette charte s'applique aux résumés IA, aux textes rédigés à la main et aux indicateurs.

## Ce que l'appli fait, et ne fait pas

| L'appli fait | L'appli ne fait pas |
| --- | --- |
| Rapporte les arguments de chaque groupe | Dire si un argument est vrai ou faux |
| Cite les propos exacts avec leur source | Qualifier un groupe (« extrême », « radical », « modéré ») |
| Montre les votes et leurs résultats | Recommander un vote ou un parti |
| Explique les procédures | Noter ou classer les députés |
| Publie des indicateurs avec leurs limites | Présenter un indicateur comme une mesure de qualité du travail |

## Règles de résumé

1. **Fidélité** : un argument résumé doit pouvoir être reconnu par le groupe qui l'a porté.
2. **Attribution explicite** : chaque argument est introduit par son groupe (« selon le groupe X », « le groupe X estime que »).
3. **Pas d'adjectif évaluatif** de la part de l'appli : ni « juste », « dangereux », « irréaliste », sauf dans une citation.
4. **Vocabulaire du groupe** : on reprend ses mots (« aide à mourir » ou « suicide assisté » selon qui parle), sans les remplacer par ceux d'un autre.
5. **Noms officiels** : chaque groupe est désigné par son nom officiel à l'Assemblée.
6. **Pas de position déduite** : sans prise de parole, un groupe est affiché « ne s'est pas exprimé », même si son vote est connu (le vote s'affiche séparément).
7. **Divisions visibles** : un groupe divisé est affiché « divisé », avec les arguments des deux côtés.

## Règles de citation

- Une citation est **exacte mot pour mot** ; une coupure est marquée par « \[…\] ».
- Une citation ne doit **pas inverser le sens** du propos (ironie, question rhétorique, citation d'un adversaire).
- Longueur : **40 mots maximum** ; le lien vers l'intervention complète est toujours affiché.
- Chaque argument a **au moins une citation** ; un argument sans citation vérifiée n'est pas publié.

## Traitement identique

- Même nombre maximum d'arguments par groupe (4), même format, même longueur cible.
- **Ordre d'affichage fixe** pour tous les textes, celui des sièges dans l'hémicycle, de la gauche vers la droite (décidé le 28 octobre 2026).
- Un audit automatique compare longueur, ton et vocabulaire des résumés par groupe (V1.1).

## Indicateurs

- Chaque indicateur affiche sa **définition**, sa **source** et ses **limites**.
- Aucun classement « meilleur / pire député ».
- La participation aux scrutins n'est jamais appelée « présence ».

## Corrections

- Tout signalement reçoit une réponse ; une erreur confirmée est corrigée dans les 7 jours.
- Les corrections sont visibles : la fiche indique qu'elle a été corrigée, et l'historique garde l'ancienne version.
- Une erreur récurrente devient un exemple d'entraînement (boucle d'amélioration, V2).

## Application

Cette charte est publiée sur la page Méthode, versionnée dans le dépôt, et reprise sous forme condensée dans chaque prompt (voir le guide de rédaction des prompts).
